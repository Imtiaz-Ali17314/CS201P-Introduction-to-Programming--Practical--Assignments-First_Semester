# CS201P – Practical Programming Assignments (First Semester)

## 📖 Overview
This repository contains the **first practical assignment** for the *CS201 – Introduction to Programming* course (First Semester). It showcases fundamental C++ techniques for processing student ID strings, extracting digits, and performing various analyses:

- Parsing alphanumeric IDs to isolate numeric characters
- Displaying digits, reversed digits, and identifying absent, even, and odd digits
- Computing the smallest and largest digits
- Generating a multiplication table for the largest digit

The program outputs a formatted report of these calculations.

## 📂 Repository Contents
- `main.cpp` – Source code for the practical assignment.
- `Spring 2026_CS201P_1.docx` – Assignment brief and specifications.
- `main.exe` – Pre‑compiled Windows binary.

## ⚙️ Build & Run
```bash
# Compile (requires a C++ compiler, e.g., g++)
g++ -std=c++17 -O2 main.cpp -o assignment1
# Execute
./assignment1
```
On Windows you can also run the provided `main.exe` directly.

## 🎯 Learning Goals
- Practice string manipulation and digit extraction.
- Learn to work with character classification functions (`isdigit`).
- Generate formatted console output and simple arithmetic tables.
- Understand basic algorithmic thinking for data analysis.
